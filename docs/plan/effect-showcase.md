# 卡牌特效验收入口实施计划

本文执行[效果系统架构 §6.1](../architecture/effect-system.md) 的开发验收入口，并覆盖 `CARD_POOL` 中的 C-01 至 C-21 全部 21 张卡牌。C-22 至 C-40 的效果由事件求时器的事件日志驱动，不在 `CARD_POOL` 中，暂无验收情景。规则数值与付费结算不在本计划范围内。

## 目标与边界

- 在首页提供仅 Vite 开发构建可见的「特效验收」入口。
- 复用生产赛道的 `RaceScene`、马匹资源、舞台缩放与挂点；使用 `CARD_POOL` 数据和固定场景驱动器展示确定性状态，不启动付费会话或修改规则内核。
- 为 C-02 增加以马体图片垂直中心为轴的纵向压缩翻面，以及一条随模拟时间取帧的螺旋拖尾突进分镜；为 C-13 增加装备从来源马挂点飞向目标马挂点的短弧线过渡。
- 把火箭与黑洞挂到马腹部锚点并随起飞根节点升降；将选中马金圈置于所有马匹精灵深度之下。
- 确认成功的 C-09 `swap` 播放 `audio.sfx_swap`，并以测试锁定；不添加 C-09 视觉特效。
- 明确禁止 C-10 重力井范围/目标特效，以及 C-11 火焰层数/满层爆发在马身上的特效。

## 表现约束

- C-02 沿用当前侧视 2D 马匹与赛道的简洁形体。用纵向压缩和翻面表达水平轴翻滚，另叠一条半透明螺旋拖尾突进分镜（16 帧、650 ms 循环）。避免体积光、屏幕扭曲、粒子爆发或另造一套材质。
- C-02 翻转以马体图片垂直中心为支点，不能围绕站立基线；分镜中心对齐同一支点、朝前、不随马体翻面，帧由模拟时间决定，不用现实时间。
- C-07 火箭与 C-10 黑洞共享按马图原点和显示尺寸计算的腹部锚点，随根节点起飞偏移整体升降。
- 玩家选中圈作为 `RaceScene` 的独立低层对象绘制，层级低于所有目标马匹，不与马体合为一个深度容器。
- C-13 让同一件装备素材从来源挂点移动到目标挂点；原持有者卸下，新持有者在到达时挂载。用短弧线和轻微到达缓动表达所有权改变，不叠加闪光、爆炸或粒子。
- C-09 只播放已有的 `audio.sfx_swap`。空过不产生 `swap` 事件，因此不播放声音；不增加镜头摇晃、闪光、拖影或换位动画。
- C-10 仅显示持有者的黑洞装备。C-11 仅显示风火轮装备与现有起飞姿态；火焰层数留在规则状态，不在马身显示。
- 减少动态效果模式下，C-02 停在稳定姿态，C-13 直接完成挂载转移；C-09 仍保留音效行为。

## 实施步骤与状态

### 1. 文档对齐（完成）

已完成：

- 在 `docs/card-design.md` 中明确各卡的风格、音效和不展示内容。
- 在 `docs/architecture/effect-system.md` 中补充现有渲染边界、开发验收入口数据流与生产隔离。

### 2. 先写表现层回归测试（完成）

测试先于实现。覆盖：

- C-02 只有指定马匹存在有效 `luckE` 状态时启用旋转表现；分镜帧由模拟时间确定，减少动态效果返回稳定姿态与首帧。
- 展示菜单中的卡牌 ID 与 `CARD_POOL` 完全一致，且每张卡都生成对应效果快照或一次性事件展示。
- 翻转缩放前后马图中心保持同一局部坐标；火箭/黑洞腹部锚点随马图显示尺寸正确计算；拖尾分镜的帧序号只取决于模拟时间，并随归属与移动保持居中。
- C-13 只对支持的装备与有效 `from`/`to` 马匹生成转移；过渡结束后最终装备归属以规则快照为准；减少动态效果立即完成。
- 首页开发入口在 `DEV` 开启时可见，生产构建不可见。
- `swap` 事件映射到 `audio.sfx_swap`，其他事件映射不变。
- C-10 的 `Field` 与 C-11 的 `burning` 层数不进入马身特效映射。

新增测试先运行并按预期失败，再实现对应逻辑后转绿。

### 3. 实现 C-02 与 C-13 场景表现（完成）

- 在 `src/game/effects.ts` 增加纯数据选择、中心支点换算、腹部锚点换算、拖尾分镜的位姿与取帧和转移动画几何，先用单元测试固定结果。
- 在 `src/game/pony.ts` 将 C-02 翻转枢轴固定到马图中心，叠加螺旋拖尾突进分镜；火箭/黑洞按腹部锚点放置并作为升降根节点子对象。
- 在 `src/game/RaceScene.ts` 为全部可玩卡生成验收快照、独立绘制低层选中圈，并消费 `steal` 事件播放同素材转移；未知装备不得留下悬空对象。
- 不改变规则事件内容、状态持续时间、轨迹或结算结果。

### 4. 增加开发验收入口（完成）

- 在 `src/App.tsx` 增加开发专用页面状态和入口；首页仅开发构建渲染按钮。
- 在 `src/ui/HomeScreen.tsx` 放置与首页现有按钮体系一致的轻量入口，不增加生产文案或资源需求。
- 新建 `src/ui/EffectShowcaseScreen.tsx` 与确定性场景驱动器，选项动态取自 `CARD_POOL` 并显示卡牌名称/效果说明；复用 `RaceScene`，提供暂停、逐步推进、重播和返回首页。
- 场景覆盖所有卡牌，重点检查 C-02 翻转中心/拖尾分镜、C-06 炸弹、装备类、C-09 音效、C-12 风、C-13 转移、HUD 状态和 reduced-motion；C-10/C-11 保持约定的身体特效禁区。
- 开发入口不得接受 `PaidRaceDriver`，不得调用钱包、网络、结算、真实时间 RNG 或写入持久化比赛记录。

### 5. 完整资源清单与验证（完成）

## 验收门槛

- 定向测试与完整 `bun test src` 通过，`bun run build` 通过。
- 生产构建的首页不含特效验收按钮；开发构建可从首页往返进入验收入口。
- 所有演示均使用确定性时间线与真实 `RaceScene` 绘制路径，不触碰规则结算与资金路径。
- C-01 至 C-21 的 21 张卡全部可从菜单选中并呈现其规则数据/事件；C-02 与 C-13 在持续、结束/转移阶段可辨认，无挂点漂移或对象残留。
- C-02 马图中心翻转保持中心坐标；螺旋拖尾分镜居中于马图中心并随马体移动；火箭/黑洞跟随马腹与起飞升降；玩家金圈被目标马匹遮挡。
- C-09 只有成功 `swap` 播放音效，且无新增交换视觉特效。
- C-10 范围与 C-11 火焰层数没有马身表现；文档、代码和测试对该约束一致。
