# 三张牌构筑：卡池研究与玩法提案

外部游戏研究日期：2026-10-01。正式卡牌以[卡牌设计](../card-design.md)和[数值规划](../plan/numerical-balance.md)为准。本文保留研究编号与尚未采用的发牌/机制提案；已采用条目直接引用正式定义，不维护另一套数值。

## 1. 探索原因

玩家每场最多获得三张卡。增加卡池会增加新鲜感，却也会降低指定配合牌相遇的概率；如果新牌仍然只有独立加速，玩家最终只需比较加速幅度和剩余时间。如果新牌必须凑齐三张指定卡才有效，构筑又会变成等待发牌许可。

本次要解决的是：在五马自动竞速、三次里程选牌、选中立即生效的玩法中，怎样让第一次选择改变第二次选择的价值，同时让第三次仍保留补救、反制和冲线取舍。这会影响效果状态、事件边界、发牌分布与链上复算，不能只靠改几个数值回答。

另一个问题来自当前实现：补给、固定速度与百分比加速是否处于同一有效强度范围。若某种资源在大部分正常比赛中根本不会耗尽，围绕该资源扩充牌库就可能建设出一个看似完整、实际很少成立的流派。

## 2. 探索目标

1. 调研《杀戮尖塔》一代、《小丑牌》原版和《土豆兄弟》基础玩法，拆出卡池、牌组、资源、触发方式与风格的设计方法。
2. 以具体卡牌、Joker、武器和道具为依据，说明哪些组合能迁移、哪些依赖长局循环，不能直接迁移。
3. 保留每场最多三次选牌、每次三选一或放弃、立即生效、gogo 只控制镜头的基本约束，提出具体的新卡与三张牌路线。
4. 给出卡池扩充顺序、规则接口与验收方法，明确哪些只是复用概念、哪些确实需要扩展实现。

调研以官方产品说明和开发者分享确认游戏结构，以社区牌库核对具体效果。下文“迁移判断”和新卡均为本研究的分析，不代表原作者的设计意图。Wiki 数值按本次读取的页面记录，不将不同版本、续作、DLC 或模组混成同一牌库。

#### 3.1.1 体力与速度的比较口径

玩家基线、完赛时间、阶梯体力收益、距离消耗暂行方案及三卡平均收益目标集中在[数值规划](../plan/numerical-balance.md)。本文不重复这些计算。比较构筑必须固定获得时点、剩余路程、其他速度贡献与力竭轨迹；名义体力不能直接乘常数距离。

### 3.2 杀戮尖塔：卡组解决连续遇到的问题

官方说明强调动态组牌、不同路线和遗物交互，并列出四名角色各自的牌池。研究限定一代，不用二代新卡解释一代机制。[官方 Steam 页面](https://store.steampowered.com/app/646570/Slay_the_Spire/)

它同时具有两个构筑层次：一局内的战斗之间选择、删减和升级卡组；战斗内反复抽取并分配有限能量。攻击解决输出，防御解决生存，抽牌提高访问能力，能力牌改变之后每次动作的收益。其深度依赖多轮战斗和反复用牌；Ponygogogo 每张选中一次后立即生效，应主要借鉴能力牌和资源转换，不照搬手牌循环。

#### 3.2.2 牌组与风格的启发

消耗、毒、小刀、格挡、球和姿态是不同接口；它们允许玩家把一张新牌放进多个已有方案。研究中的流派名称用于描述配合，不应变成“拿到第一张后只能追该流派”的玩法限制。三张牌中，一张补弱点的泛用牌可能比第三张同类牌更有价值。

名称和画面通常指向直接动作、身体代价或角色能力，关键词负责压缩组合语义。适合本作的做法是“梗名 + 一眼看懂的行为 + 公开词条”，例如【名刀司命】真的挡一次死亡，【装备大师】真的拆装备。卡面不必直接写“与某张卡组成流派”。

Mega Crit 的 GDC 分享把平衡目标概括为让每张牌有位置，同时避免过分扭曲整体；也强调数据只能作为证据，需要结合试玩反馈。本作应按检查点、已有构筑和比赛状态看卡牌价值，不能仅按总选取率调强弱。[开发者 GDC 原始演示](https://media.gdcvault.com/gdc2019/presentations/Giovannetti_Anthony_SlayTheSpire.pdf)

### 3.3 小丑牌：少量常驻牌改变每次结算

官方列出的原版结构包含 150 张 Joker、15 种起始牌组，以及塔罗、星球、幻灵和优惠券等不同工具。普通扑克是参与计分的载体，Joker 是常驻规则，牌组改造提高触发概率，经济提供找牌能力。默认 Joker 槽有限，所以单张规则牌的取舍本身很重要。[官方 Steam 页面](https://store.steampowered.com/app/2379780/Balatro/)、[Joker 牌库](https://balatrogame.fandom.com/wiki/Jokers)

| 有限续航 | [Ice Cream](https://balatrogame.fandom.com/wiki/Chips)：筹码随出牌消耗；[Popcorn](https://balatrogame.fandom.com/wiki/Jokers)：倍率随回合减少；[Acrobat](https://balatrogame.fandom.com/wiki/Acrobat)：最后一手才强 | 临时过关工具与终局工具不是同一种牌 | 第三检查点提供短时高收益，而长时启动牌在末段允许变弱，不能要求每张牌各阶段同样好用 |
| 指向性复制 | [Blueprint](https://balatrogame.fandom.com/wiki/Blueprint)：复制右侧兼容 Joker；[Brainstorm](https://balatrogame.fandom.com/wiki/Jokers)：复制最左侧兼容 Joker | 复制对象、兼容性和位置明确；不是任意系统状态都复制 | 本作没有手动整理常驻卡槽，不能直接照搬左右位置；只考虑事件白名单内的复演 |

#### 3.3.2 牌组怎样让配合更容易发生

[Abandoned Deck](https://balatrogame.fandom.com/wiki/Decks)去掉起始人头牌，使不计分人头牌的路线更稳定；Checkered Deck 只用两种花色，使同花更容易；Painted Deck 用手牌容量交换 Joker 槽；Plasma Deck 改变筹码与倍率的计算关系。这些起始牌组改变的是触发环境和资源结构，不只是赠送几张强牌。

本作已经有五马身份、牌堆、天气与体力，不必同时增加职业和赛前套牌选择。先让现有状态成为稳定接口。如果之后验证随机牌库不足以提供配合，再讨论公开的小型主题牌池；不能把它挂到私有收藏筛选上，因为当前收藏不证明有奖抽牌资格。

小丑牌的视觉和名称常把日用品、文化符号或概念变成一句规则，玩家通过反复触发看到结果。对本作最值得迁移的是“我装了两条规则，比赛开始以另一种方式运行”。不迁移无限倍乘、巨量指数数值和多轮经济积累；赛马要在短时运动轨迹里读懂因果。

### 3.4 土豆兄弟：属性收益、代价与寻找组件的概率

土豆兄弟是自动攻击的竞技场 roguelite，基础玩法允许最多六把武器，波次之间买武器和道具。它不是传统抽牌战斗；需要研究的是其构筑接口和供应机制。[开发者发布的官方 Steam 说明](https://store.steampowered.com/app/1942280/Brotato/)

#### 3.4.1 武器、道具和角色形成三层构筑

| 对象 | 代表效果与来源 | 设计作用 | 对本作的迁移 |
| --- | --- | --- | --- |
| [SMG](https://brotato.wiki.spellsandguns.com/SMG) | 低单次伤害、高频攻击，吃远程伤害收益，也频繁尝试生命窃取 | 同样的属性，在不同频率载体上价值不同 | 比较短时百分比、永久固定值和里程爆发的实际覆盖，不用面板数字判断强弱 |
| [Stick](https://brotato.wiki.spellsandguns.com/Stick) | 额外木棍提高自身基础伤害，同武器类别另有组合加成 | 专精有回报，组件容易理解 | 共享功能标签可以奖励专精；当前无重复 cardId，不能直接设计“三张同名牌” |
| [Wrench](https://brotato.wiki.spellsandguns.com/Wrench) | 不同品质生成不同炮塔 | 装备是规则载体，升级也可能改变功能 | 装备牌优先与覆盖、回收和槽位交互，不把升级一律做成数字变大 |
| [Sniper Gun](https://brotato.wiki.spellsandguns.com/Sniper_Gun) | 使用远程伤害与射程等缩放 | 辅助属性成为输出接口 | 当前体力能通过“支付”和“兑现”影响速度；冻结的马匹性格参数不作为可写资源 |

本作选马当前不改变玩家基础参数和对手参数集合。角色初始能力会改变速度、消耗与构筑偏好，名单与能力以小马角色计划为准。本轮更合适的是把一张牌做成局内的有限承诺，比如无装备或支付体力。

#### 3.4.2 构筑可靠性来自供应，不全靠卡牌效果

土豆兄弟商店可以锁定道具，保留到刷新或下一波；武器供应存在同武器、同类别和全池的抽取分支，早期还有类别支持；角色标签也影响部分道具供应。具体概率应以相应版本页面为准，这里借鉴的是“玩家选过一个方向后，后续有一定机会找到兼容组件”。[商店与供应规则](https://brotato.wiki.spellsandguns.com/Shop)

当前 Ponygogogo 的有奖牌堆在入场时已固定，不能在第二检查点偷偷依据第一张牌重新抽池。若需要主题倾向，应在入场派生规则中公开定义并冻结，不根据浏览器状态临时补牌。本轮优先提高原卡池的共享接口密度，暂不变更派生规则。

### 3.5 三张牌怎样产生策略深度

#### 3.5.1 三次决策，多个自动触发

三个检查点不意味着每张牌只能产生一次影响。现有风火轮有有限周期爆发，不义游戏会多次交换。新牌可以把选牌时的一次决策，展开为后续有限的资源阈值、里程阈值或状态反应。

最适合的结构是：

```text
第一张：提供立即可用的基础收益，并建立方向
第二张：利用已有状态，或补上第一张造成的弱点
第三张：按剩余路程、体力、危险与对手状态决定冲刺、保命或反制
```

这不是强制角色分工。第三次可以拿启动牌，只要剩余路程足够；第一张也可以是局势反制牌。衡量标准是同一候选牌在不同已选牌和比赛状态下，是否出现合理的价值反转。

仅有百分比加法不会自动形成机制配合。两张加速相加可以有非线性的冲线时间收益，但“起飞改变炸弹可触发性”“体力消耗使亢奋有价值”“回收最后一件装备开启无装备收益”才是在改变另一张牌的条件。

#### 3.5.2 两张即可成形，第三张不能全被占死

常规路线至少要有一个两张牌的可见配合，第三张留给局势。指定三 ID 的特殊结算可以作为彩蛋存在，但不适合作为新增流派的主要结构。

用简化均匀池说明稀释风险：首张牌已确定，剩余 `N−1` 张中有 `m` 张兼容牌，下一面板三张均匀无放回，则至少看到一张兼容牌的概率为：

```text
P = 1 − C(N−1−m, 3) / C(N−1, 3)
```

| 总卡池 N | 只有一个指定搭档 | 有六个可替代搭档 |
| --- | --- | --- |
| 26 | 12.00% | 57.87% |
| 38 | 8.11% | 42.15% |
| 50 | 6.12% | 33.02% |

另一个均匀模型中，三张指定卡恰好分布于三个三张面板的概率为 `27 / C(N,3)`；`N=26` 时约 1.04%。这只是“有机会每轮选一张构件”，不是胜率，也不包含玩家是否真的选择。现有彩蛋有两个可替代的薄肌构件，仍不能据此直接算实际触发率。

以上没有纳入 rare 尾部保底、刷新、自动选牌、提前冲线和真实派生算法，**不能作为当前比赛的实测概率**。它说明：扩大卡池时，增加可替代搭档比增加更多只能和指定 ID 配合的牌更重要。

建议每个主要状态至少连接三种用途：收益、代价/反制、退出/兑现。兼容关系也不能只按“拥有同一标签”统计，要检查剩余时长、取得顺序和资源能否真的产生收益。

#### 3.5.3 快照与持续条件各有位置

- “选中时最近的前方对手”只取一次目标，之后对它施加有限时减速。它强调选择时机，不引入随身位反复切换目标的动态场。
- “起飞时额外加速”随状态变化生效，需要在起飞来源获得、到期、装备覆盖和转移时重新计算。
- “体力首次低于阈值”必须在越过阈值的规范事件时刻触发，不能由浏览器帧检查；若选中时已满足，则当刻触发一次。
- “跑过额外里程”读取 `dist`，不能读取 `pos`；交换不能提前领取，也不能取消已经消耗的触发次数。

状态可以共享，事件必须有边界。三张牌不需要无限循环来制造强组合。

### 3.6 三十张候选卡

`N-01` 至 `N-30` 是研究编号，不占用正式 cardId。以下数值是**可复现实验的初始假设**，不是平衡定案；使用当前规则尺度：秒为模拟秒，体力容量按玩家/对手分别取值，固定速度为赛道单位/秒，百分比进入现有加算区。名称是梗与美术方向的候选，不表示已确认外部梗来源。

共同边界：

- 增益各自计时；死亡只重置运动基础速度，所有卡牌贡献、期限、层数、监听与进度保留。
- 持续恢复钳在各自容量，所有直接补给可超上限；已有力竭达到各自退出阈值才解除。
- 卡牌自身不增加第四个检查点，不改变冻结的基础加速度/上限，不写 `dist`，不改结算名次。
- 跨马目标按具体卡牌筛选；五谷丰登给全部五马补给，其他目标动作限未冲线马；相同候选条件按 `horseId` 升序裁决。新负面效果不会自动获得【目中无人】现有炸弹/风/交换免疫的规则，须逐类声明。
- “立即小增益”旨在减少空抽，但不能让所有条件牌都严格优于现有泛用牌；机会成本仍由占用一张选择、条件和代价承担。

实现层级：**A** = 组合现有运动/资源/装备概念，但仍需接入有奖效果分支；**B** = 新增明确门控、快照或有限事件；**C** = 新的替换反应、复制或发牌状态。层级不等于完成度，也不承诺改动量。CPU 栏仅为候选是否适合自动使用的判断，启用须单独验证对手卡池分布。

| N-27【百花齐放】 | 本场已获得的卡中，每一种不同主功能类型给 +7% 速度，持续到比赛结束，最多三种 | 自身算“动力”；补给、装备、干扰、改签也可与之组成分散构筑。按实际获得历史计数，装备被偷不会抹掉类型 | B / 否 |
| N-28【刷新贷】 | 后续刷新额度 +2；自己速度 −10%，10 秒 | 增加2次额度并付出即时代价；现有C-05为3次，本提案不构成更高额度；额度只用于后续面板，第三检查点基本不适合拿。不会绕过尾部空间限制 | A / 否 |
| N-29【保留意见】 | 下一检查点保留当前没选的两张候选，再从前游标取一张新牌；只保留一次 | 保留已看见的优质选项，代价是少看两张新牌且当前不获运动收益；仅适合前两个检查点，需要变更发牌规则 | C / 否 |
| N-30【专业对口】 | 速度 +8%，15 秒；选中前已获得的两张牌若主功能相同，另加 +15% | 两张同功能即可兑现，不要求同名；和百花齐放形成专精与分散的取舍。前段拿只有小收益 | B / 否 |

主功能类型仅用于 N-27 / N-30 与图鉴说明，每张卡一个：动力、补给、装备、干扰、改签、外观。例如火箭是装备，不同时算动力和补给；起飞加速是动力；染色是外观；理解孙学按其主要规则归干扰。分类进入公开冻结的规则表，不能由前端文字推导。

N-29 是发牌变体，不能沿用当前 `cursor += 3`。下一面板先复用两张拒选牌，再消费一张新牌；这两张此前展示过但未获得，不复制 cardId，也不允许已选牌回流。每场仍至多三次获得，刷新仍从尾部取未消费牌。它与 C-04 / C-03 的组合需要明确定义：断卡优先阻止面板；自动选择可在保留后的三张中选择，但不允许人工刷新。由于涉及游标、候选复算和 UI，暂不进入首批。

### 3.7 八条三张牌路线及转向

以下是可用于原型试玩的选择路线，不是假定真实发牌一定提供三张，也不声称必胜。

| 路线 | 前两张怎样成立 | 第三张的真实选择 | 失败面 / 转向 |
| --- | --- | --- | --- |
| 体力换爆发 | 火箭 + 狂暴引擎：省消耗支持高收益 | 预计见底选亢奋；体力不足但还没力竭选肾上腺素；资源足够则直接冲刺 | 黑洞会覆盖火箭；亢奋持续40秒，不是永久免除后果。若引擎来得很晚，可不补资源 |
| 先歇再跑 | 摸鱼 + 梭哈：恢复窗口支持后续支付 | 备用粮提高支付后容错，或年轻人不讲武德压制前方对手 | 剩余路程短于准备期则不成立；梭哈先拿会提前付出体力，不能把顺序视作可随意交换 |
| 空中路线 | 中国马能飞 / 风火轮 + 纸飞机 | 逆风时逆风翻盘；危险时名刀司命；没有风和危险则普通加速 | 起飞到期或装备被偷会关闭额外增益；起风了仍有方向风险，不预设必定顺风 |
| 地面轻装 | 接地气 + 空手道：地面、无装备同时有效 | 对手顺风选公平竞争；接近前方马选年轻人不讲武德；低体力选补给 | 起飞会关闭接地气；火箭会压低空手道收益；拿风火轮避炸弹意味着主动放弃部分输出 |
| 毛发构筑 | 任一毛发+跑马灯获得恢复+150% | 第三张选另一颜色，可同时获得速度+60%与恢复+150%；也可选独立补给/速度 | 两颜色+跑马灯占满三次选择，不能再同时凑版本答案 |
| 装备回收 | 火箭 / 彩虹猫 + 装备大师：将剩余价值换爆发与体力 | 回收最后一件装备后选空手道；回收尾部后可以再装尾部；也可按对手状态反制 | 火箭尚有很长时长时拆掉可能亏；装备大师自动拆最短的一件，必须先看清将拆哪件 |
| 延迟代价管理 | 蓝色小马 + 名刀司命：在其到期前覆盖一次死亡 | 预计盾先被炸弹消耗，可转起飞避地雷；若能提前冲线则拿终局爆发 | 盾不足以同时抵挡所有死亡；蓝色小马没有起飞效果。来劲应对力竭，名刀应对死亡，触发条件独立 |
| 里程成长与终局 | 登神长阶 + 泛用加速 / 资源牌：正常运动触发有限成长 | 各退一步可能用捷径换掉尚未兑现的里程奖励；也可保持配速拿末段爆发 | 死亡保留固定速度与成长进度，运动基础速度仍需重新加速；传送不是额外里程 |

这八条路线的第三张都应允许换成别的答案。现有【版本答案】保持为独立彩蛋，不把新卡都做成改写结算第一名的拼图。常规构筑的成果应当表现为更快冲线、更少受干扰或更好管理代价。

#### 3.7.1 同一个末段面板，不同构筑应选不同牌

设第三检查点出现【梭哈】【逆风翻盘】【年轻人不讲武德】：

- 空中路线、逆风仍生效：逆风翻盘可能同时提供自身加速与逆风抵消。
- 地面路线、体力尚足、前方没有近距离对手：梭哈可能更合适。
- 支付后体力风险较高、前方对手在范围内：年轻人不讲武德可能更合适。

“可能”表示需要比较规范剩余轨迹与代价，不是未定义规则。验证时必须固定三种状态和相同候选面板，证明最佳选择确实发生反转；如果永远都是梭哈，就调整收益/代价或删掉被支配的候选。

### 3.8 发牌、信息与卡面表达

#### 3.8.1 现有卡池与扩展边界

当前正式卡池为40张；已采用研究条目见§3.6的正式定义链接。进一步扩池前，以真实派生候选、三次选择、条件覆盖与剩余路程验证搭档可达性；未采用的复制、保留候选、定向交换和天气消除机制各自独立验证。

#### 3.8.2 三种分布方案的取舍

| 方案 | 怎样产生牌堆 | 收益 | 代价与判断 |
| --- | --- | --- | --- |
| 保持当前全池派生 | 仍先派生 rare 尾部，再派生前 12 张 | 当前可复算流程不变，规则变化集中在卡牌 | **第一步采用**；靠共享状态和补齐空位增加配合。扩池后按真实派生统计 |
| 入场公开主题牌池 | 入场先派生主题，再从公开冻结的兼容子集派生 14 张；保留足够泛用/反制组件 | 提高搭档可达性，让不同场次有方向 | 属于新发牌规则；每个可选子集必须 ≥14 张、rare ≥2；需统计主题对强度的影响。只有全池验证失败后才考虑 |
| 按第一张牌动态倾向后续供应 | 每次选牌后依据标签重新产生后续候选 | 构筑更容易续上 | 与当前入场固定 14 张牌堆冲突，会引入新的生成与验证状态；本轮不采用 |

无需先加商店、手动出牌、额外卡槽、职业树和第四次选择。先证明三次选择内部存在价值反转，再决定供应是否是主要瓶颈。

#### 3.8.3 未来牌堆并不秘密

当前牌堆由公开 seed 和入场哈希派生，熟悉规则的人可以重建后续候选与尾部牌，CPU 三张牌也能从入场输入复算。UI 没有展示，不等于信息被密码学隐藏。因此：

- 不把“猜未来会出现什么牌”当成长期公平的策略来源，也不把看牌工具当成非法玩法。
- 当前面板优先解释已经生效的状态和代价；是否展示完整未来牌序，是后续产品选择，不是新增随机机制。
- 由未封存的选择块决定的风向或交换目标仍存在尚未确定的输入；“初始牌堆已知”不等于“全部未来结果已知”。

#### 3.8.4 玩家要看懂的是取舍

卡面保持一条主要效果和一条条件/代价。面板可以补充当前事实，例如“起飞额外增益生效”“将消耗 300 体力”“拆除彩虹拖尾”，让玩家不必记所有状态期限。

对起飞、亢奋、重生、装备槽与毛色使用现有表现词条；不把每张新牌都包装成新术语。不能只展示预计名次或“推荐这张”，否则玩家只是在确认算法答案。若给出预计收益，要包含假设和未确定随机效果，不用一个数字掩盖风险。

美术优先表现机制发生的瞬间：梭哈是体力下注，纸飞机是轻装飞行，跑马灯是颜色改变用途，装备大师是拆旧件，名刀司命是一次盾破碎，登神长阶是在真实里程刻度领取奖励。无需先制作图片；专属视觉按卡牌设计验收。

### 3.9 接入边界与长期接口

卡牌规范来源为cardRules.ts；已采用的支付、消耗修正、历史颜色数量门控、装备监听/续期、死亡与力竭拦截、独立里程成长均进入TS/Solidity。未采用的复制、保留候选与定向交换需要新增有限机制和两端回归，不能仅填写卡表便宣称实现。

事件、实例、最长比赛与gas必须按合法输入验证。新规则改变生成物与规则哈希，既有会话继续绑定原求时器。

### 4.3 策略验收：证明取舍成立

规则测试通过，只证明牌按定义运行，不证明构筑有趣。策略验证需要三组不同证据：

**机制场景**：固定初速、候选面板、体力和局势，比较同一张牌的早拿/晚拿、先启动/后配件、受击/未受击、地面/起飞、有风/无风。记录五马时间、实际触发次数、有效覆盖路程、体力支出与死牌原因。

**真实派生**：固定公开 seed 和锚样本，从真实 14 张派生规则生成场次；分别统计不刷新、合法刷新、自动选择、提前冲线与主动放弃。玩家不能控制入场牌堆，不以人为拼出的强组合代替可达性。不同下注档位单独报告；新 CPU 牌先隔离验证，再加入分布。

**真人试玩**：检查玩家在 20 秒现实选择窗口内能否复述代价、辨认正在生效的门控、看到组合触发，并在第二或第三次主动转向。一次规则正确但玩家看不懂的选择，仍需要改善表达。

建议报告以下指标，避免单用总选取率：

| 指标 | 定义 / 判据 |
| --- | --- |
| 兼容可达性 | 首张不同状态牌之后，剩余实际面板至少提供一张可发挥的兼容牌的比例；区分“在牌堆里”“被展示”“被获得”“实际触发” |
| 条件激活率 | 被选后核心条件真的满足、兑现过收益的比例；不得把兜底 +5% 当成核心组合已成立 |
| 价值反转 | 固定候选三张，至少在两类可达状态下最佳选择不同；无反转时检查被支配的牌 |
| 单牌与组合收益 | 同基线比较时间/名次变化；机制配合另检查条件或代价如何改变，不能只用非线性冲线时间差宣称存在联动 |
| 第三张自由度 | 成形两张组合之后，是否有补给、反制或冲刺的合理分支；无需每条路线都再追一个指定 ID |
| 普通代价可见性 | 玩家是否会因支付体力、失去装备或等待启动而放弃强牌；如果代价总不兑现，优先改代价结构 |
| 死牌与支配 | 按检查点/体力/对手状态记录无收益候选；同输入下无任何优势的卡要删减或改角色，不靠提高稀有度隐藏 |

小规模候选每轮最多 `4³=64` 个选择/放弃分支；合法刷新和选择时间会扩展分支空间，不能将 64 宣称为完整玩法搜索。选牌时间先选开窗首个合法秒、中段、末个合法秒作为诊断点，再对发生价值反转的边界细分。

第一轮至少比较三种策略：只取立即速度收益；按共享状态/资源配合选择；按可达分支搜索的分析上界。搜索上界要区分只读取当时已知输入与预知未来随机锚，后者仅用于机制诊断，不能冒充真人策略。全池 seed 样本使用独立的调参集和留出集，避免只对示例局有效。

## 5. 注意事项与补充

- 研究支持的主方向是**两张建立机制，第三张按局势调整**。三张上限可以保留；需要验证的是资源代价、接口密度和供应可达性，而不是先扩操作数量。
- 起飞、体力、装备、毛色和死亡已有明确玩法意义。先扩这些状态的用途；主功能分类服务角色初始能力，不引入全面元素、职业或战斗体系。
- 三十张是供筛选的候选，不是全部上线清单。已采用条目使用正式卡池定义；复杂复制、保留候选和定向交换各自独立验证。
- 卡牌原语属于架构语言，不等于当前有奖引擎的任意扩展能力。尤其死亡替换反应、临时固定值、任意体力修正与新发牌状态，必须同时落实事件顺序、字段和跨实现证据。
- 本文研究不作为部署或数值平衡证据；当前卡牌定义以正式文档和规范表为准。
