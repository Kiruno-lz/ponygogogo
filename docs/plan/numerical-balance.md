玩家运动、体力容量、恢复与力竭参数已接入；电脑马使用同一基线，只有速度上限按 §1.3 随机偏移。距离消耗11.5/1000是未接入的暂行方案；当前代码常规消耗仍为20体力/秒。第2章计算距离消耗方案，第6章验证当前生产代码，二者分别报告。

### 1.3 电脑马难度与返还率

本节返还统计在此次品质调整前测得；速度偏移参数保持不变。新稀有子集会改变派生牌堆和稀有专精触发，现行RTP须按第6.9.5节重跑验证。

| 项目 | 规则 |
| --- | --- |
| 电脑马基线 | 与玩家相同：起跑 300、加速度 150、体力容量 300、消耗 20/s、恢复 10/s、力竭与死亡后恢复规则相同；角色能力按名单生效，奶龙容量加成只给玩家 |
| 唯一差异 | 速度上限 `C_i = 1800 + o_i`；`o_i` 为 `[100, 500]` 内均匀整数，四匹电脑马独立抽取 |
| 随机源 | `o_i = 100 + H(seed, blockhash(b_0), 0, "horse.cap", g) mod 401`；`b_0` 为开场交易所在区块，`g` 为电脑马按 `horseId` 升序的序号 0–3 |
| 下注档位 | 只决定下注额与赔付，不影响电脑马 |
| 规则版本 | `PLAYER_BALANCE.cpuCapOffsetMin / cpuCapOffsetMax` 进入玩家基线哈希与规则哈希 |

随机源取开场交易所在区块的哈希，不取上一区块哈希：签名开场交易时 `blockhash(block.number − 1)` 已经公开，合约可在同一笔交易内算出电脑马难度，不利即回滚，只挑弱对手入场。EVM 内 `blockhash(block.number)` 为 0，`blockhash(b_0)` 在后续区块封存后才确定难度，此时下注已锁定。

返还率以专家策略校准：已知公开牌堆，每个检查点穷举合法选牌、放弃与刷新，以期望返还倍率为目标（口径见 §6.6）。规则、牌堆与对手参数都可公开复算，机器人能执行该策略；专家 RTP 低于 1 才保证任何策略长期不盈利。对手使用对 CPU 无作用的实验角色，等于玩家可挑选的最有利名单，结果为返还率上界。

同口径参照：C16→C22→C07 21.3%，C07→C26→C16 12.0%，C07→C08→C30 10.0%。无论顺序，三件套在第 3 检查点才齐，+200% 只覆盖最后约四分之一赛程；先取 C29 让第一种毛色的恢复更早生效。

C10 场作用于全场后，最坏合法场次 Foundry gas 上升 13–50%（最高 worst-event-count 7.62M 不变），300 s 单井投影 1200 步、11.38M，均低于 23.5M 单笔上限。
