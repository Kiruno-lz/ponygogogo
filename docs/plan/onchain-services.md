# 链上服务交付

## 1. 责任边界

Mera 恢复根 EOA；Alchemy 为每个根身份创建独立 `sma-b` 智能账户并发送交易；PonyGame 验证五马规则和排名；PonyVault 管 ERC-20 资金；Envio 只从最终合约事件建立历史与统计。浏览器绘制与预览相同规则，但不决定奖金。无需 Game Server、TEE 或结果签名者。具体协议见[链上架构](../architecture/onchain.md)。

## 2. 交易数据流

1. 根 EOA 恢复智能账户；账户持有固定 ERC-20。入场时批量完成精确授权、Vault 充值和 `openSession`，返回 sessionId、seed、入块时间 `T0`、入块号 `b_0`、规则版本、赔付快照及期限。
2. 浏览器由 seed、入场块哈希和卡集合生成候选牌；每次实际选择/主动放弃写入 PonyGame，合约存交易入块秒级时间 `Ti` 与块号 `b_i`，最终复算候选、刷新、顺序和 20 秒期限。断卡、自动选择及超时均由冻结规则唯一推导。
3. 后续区块读取 `blockhash(b_i)` 并封存；可并入后续选择或结算。C-09 多次交换复用获得该卡的 `b_i`，以触发序号派生不同方向。自动选牌复用先前已锁定锚，超时不产生新随机锚。临近窗口过期须单独封存，过窗不可由浏览器补值。
   规则时钟使用真实经过时间：正常 `dτ/dt=1`，选牌慢放 `0.1`。浏览器流畅预览，交易确认后按 `T0/Ti` 校正；不使用区块高度换算比赛时钟，也不信任浏览器自报毫秒值。
4. 浏览器展示过程与冲线预览，提交结算交易。PonyGame 直接求五马冲线时间并排出 `rawRank`，从已获得卡牌检测【版本答案】得到 `settlementRank`；Vault 仅以后者原子记账并发事件。无场区间解析积分，重力井生效区间按实时距离做定点积分。超时按显式退款路径处理。
5. Envio 索引 `SessionOpened/CardChosen/RandomAnchorSealed/SessionSettled/SessionRefunded` 与 Vault 事件。网页查询战绩，资金状态始终以 RPC/合约为准。

## 3. 修改位置

| 位置 | 工作 |
| --- | --- |
| `src/race/core/`、`src/race/cpu/`、`src/race/modules/` | 五马事件求时与两层名次；体力—固定加速度、性格基础速度上限、百分比乘当前基础速度、固定值外加；无场解析积分、有重力井时定点积分；CPU 无追赶/噪声；真实时间慢放、C-09 四赛道交换、C-11 满层爆发；gogo 不进入规则 |
| `src/game/` | gogo 频率只偏移同一摄像机，玩家马不出屏，五马相对坐标不变；显示链上随机确认/预览状态 |
| `src/chain/` 与钱包适配 | 智能账户、选择/封锚/结算/退款交易，按调用 ID 和哈希恢复；保留本地 mock 作为免费 Demo |
| `contracts/` | PonyGame 五马复算与随机锚、PonyVault 资金预留及权限 |
| `envio/` | 事件模型、重组回滚、比赛和玩家统计 |
